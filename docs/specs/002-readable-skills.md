# 002 — Понятные скиллы и осмысленные сборки

Дата: 2026-10-31. Статус: реализовано и проверено, версия 0.2.0. Основание: пользователь попросил 30-минутный цикл
«поиграл → изменил → снова поиграл», понятные скиллы и более интересные решения.

## Критерии

1. Основной интерфейс и все названия/объяснения улучшений — по-русски. Карточка объясняет,
   что делает скилл, показывает текущий и следующий результат в числах и короткий совет.
   Числа рассчитываются теми же формулами, что и бой, с учётом текущей сборки.
2. Три новых явно различимых механики: взрывные пули (урон соседям), ледяные пули
   (замедление без полной остановки босса), таран (урон каждому противнику один раз за рывок).
   Все эффекты видны квадратными контурами/цветами; никаких круглых ассетов.
3. На пятом уровне — один выбор специализации на весь забег. Три пути с понятными
   преимуществами и потерями: дальний урон, ближний контроль, мобильность. Карточка честно
   показывает цену. Выбор не отнимает обычное улучшение уровня; обе очереди сохраняются.
4. TAB открывает сборку и приостанавливает игру. Видны реальные характеристики оружия,
   приобретённые навыки, специализация и рецепты сочетаний с текущим прогрессом.
5. Рецепты помогают планировать: ионная буря, пробивающий веер, ледяной разлом. Игрок видит,
   чего не хватает; открытие даёт заметную обратную связь. Есть одно бесплатное обновление
   обычных карточек за забег, без обхода лимитов и без потери опыта.
6. Повторить тесты симуляции и Windows-сборку. Добавить поведенческие проверки взрыва,
   замедления/восстановления скорости, тарана, выбора специализации, очередей и предпросмотра.
   Поиграть автоматическим пилотом до/после, осмотреть реальные экраны на 1280×720.
   Не называть автопилот ручной игрой. Сохранения пользователя не затрагивать.
7. Обновить состояние, журнал итерации и GitHub после последней проверки.
